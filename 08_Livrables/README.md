# Livrables du groupe — sujet 2

Ce dossier contient le travail d'analyse du groupe, pas des sources : rien ici n'est indexé ni citable par la dataroom.

- `modele-greenup-2027.xlsx` — le classeur : chaque chiffre publié vient de `00_Admin/register.csv` (onglet Entrées), seules les cellules jaunes (onglet Hypothèses) se modifient, tout le reste est formule.
- `dossiers-sujet-2.html` — un dossier par rôle : réponse, raisonnement, chiffres sourcés, questions du jury. Généré depuis le registre et le classeur recalculé.
- `texte/role-1.md … role-6.md`, `recommandation.md`, `outils-ia.md` — la prose du rapport, écrite par le groupe dans l'éditeur web. Un chiffre se cite par son jeton (`[F12]`, `[D3]`, `[T1]`) : le rapport imprime la valeur du registre et sa source. `rapport-sujet-2.docx` / `.pdf` et `controle-citations.md` se régénèrent à chaque poussée quand un texte a changé (`dataroom report`).
- `scripts/` — les générateurs (`build_model.py`, puis recalcul LibreOffice, puis `build_dossiers.py`, puis `build_report.js` via `dataroom report`).
